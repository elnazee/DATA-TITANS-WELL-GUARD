# Public release data policy

The original competition data are restricted to authorized datathon use. Source data becoming accessible to entrants **does not authorize open distribution**. This public release includes Python/SQL source code, saved aggregate historical benchmark results (publication subject to organizer approval), and an **entirely fictional** interactive well-level demonstration.

## Public Streamlit records

Every fictional well ID in the pattern `DEMO-####`, every fictional operating sector, all example risk scores, sensor readings, performance trends, recorded events, job costs, losses, and diagram coordinates are generated by `demo_data.py` from a fixed random seed. These data do not represent actual Strathcona wells, are not anonymized copies, and should not be used to estimate actual field results.

Only the saved aggregate research metrics in `public_data/` and the source inventory/missingness facts in the Data Reliability view describe the original research dataset. Those real aggregate facts must not be conflated with synthetic per-well graphics.

## Never place in GitHub or public hosting

- `daily_production.parquet`, `well_jobs.parquet`, `production_failures.parquet` or other restricted raw data
- Actual well identifiers, coordinates, private ranking scores, real well-level time series, maintenance/event details, or raw/derived private exports
- Private trained models, pickles, cached data, credentials, API tokens, `.env`, secrets or screenshots revealing confidential records
- Any local private `data/`, `outputs/` or `logs/` folder or the separate `02_PRIVATE_LOCAL_WELLGUARD` application bundle

## Verify before publishing

Run `python scripts/publication_preflight.py`, inspect files/commits, confirm notebook cells have no saved sensitive outputs, and confirm organizer/data-owner permission for even the aggregate metrics. The static checker does not establish confidentiality compliance, and it does not verify model results. Team should also check screenshots, slides and videos.

The separate original `research_source/app.py` is source for an **authorized local private application**; it cannot power the public demo without private inputs, and those inputs must not be uploaded to Streamlit Community Cloud.
